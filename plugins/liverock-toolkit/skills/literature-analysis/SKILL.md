# 논문 탐색과 분석

탐색과 분석은 별개다. 탐색은 스크립트가 하고, 분석은 워커가 한다. 탐색 결과를 사용자가
고르기 전에 분석으로 넘어가지 않는다 — 안 고른 논문을 읽히면 쿼터만 쓰고 버린다.

## 1. 탐색 — 모델이 읽지 않고 스크립트로 뽑는다

검색어를 브라우저로 훑지 않는다. 검색 결과 페이지를 모델이 읽으면 광고·추천·무관한 항목까지
컨텍스트에 들어오고, 같은 검색을 다시 할 때마다 그 비용을 또 낸다. `scripts/search_papers.py`가
OpenAlex API를 호출해 표로 돌려준다.

```text
python scripts/search_papers.py --query "검색어" --trusted-file references/trusted-sources.md
```

| 옵션 | 언제 쓰나 |
| --- | --- |
| `--year-from` / `--year-to` | 최신 동향만 볼 때, 또는 특정 시기 연구를 찾을 때 |
| `--trusted-only` | 신뢰 목록의 저널만 남긴다. 후보가 너무 많을 때 |
| `--per-page` | 기본 10. 더 넓게 보려면 올린다 |
| `--json` | 결과를 다음 단계에 파일로 넘길 때 |

출력 표의 "신뢰" 열은 `references/trusted-sources.md`에 등록된 저널·도메인에 O가 붙는다.
**O가 없다고 나쁜 논문이 아니다** — 아직 목록에 없다는 뜻일 뿐이므로 후보에서 임의로
빼지 않는다.

검색이 실패하거나 결과가 0건이면 검색어를 바꿔 다시 돌린다. 이때 결과를 지어내지 않는다.

### 신뢰 사이트 목록 관리

사용자가 "이 사이트는 믿을 만하다", "여기 것만 봐줘" 같은 말을 하면
`references/trusted-sources.md`에 `이름 | 도메인` 한 줄을 추가한다. 도메인은 모르면 비워도
된다. 사용자가 말하지 않은 사이트를 임의로 넣지 않는다 — 신뢰 판단은 사용자 것이다.

### 스크립트로 안 되는 것

OpenAlex는 서지정보와 초록까지 준다. 본문 전문은 주지 않으므로, 본문을 읽어야 하는 분석은
사용자가 PDF를 주거나 OA 링크를 열어야 한다. 표의 `oa_url`이 비어 있으면 그 논문은 초록까지만
확인된 것이고, 그 사실을 사용자에게 알린다.

## 2. 고르기 — 사용자가 정한다

표를 보여주고 어느 논문을 읽을지 사용자에게 받는다. 임의로 상위 몇 개를 골라 진행하지
않는다. 검색 순위는 인용 수·키워드 일치로 정해지는 것이라 이번 연구에 무엇이 중요한지를
반영하지 못한다.

읽을 편수가 정해지면 워커를 띄울지 판단한다.

| 상황 | 처리 |
| --- | --- |
| 1~2편이고 초록만 보면 된다 | 직접 읽는다. 워커를 띄우는 비용이 더 크다 |
| 3편 이상이거나 본문을 읽어야 한다 | 논문 하나당 워커 하나로 나눈다 |

나눌 때는 `research-orchestration`으로 쿼터 예산을 정하고(1절), `agent-orchestration`으로
기동한다. 논문끼리는 서로의 결과를 필요로 하지 않으므로 병렬로 돌린다.

## 3. 분석 — 추측이 들어가면 결과를 못 쓴다

논문 하나당 `assets/paper-note.md` 서식으로 정리한다. 워커에 맡길 때는 이 서식을 브리핑의
출력 형식으로 싣는다.

정리해야 하는 것은 넷이다.

| 항목 | 무엇을 적나 |
| --- | --- |
| 출처 | 저널·사이트 이름과 URL 또는 DOI. 저자는 적지 않아도 된다 |
| 변인 | 독립·종속·통제변수를 각각 구분해 적는다 |
| 분석 | 그 실험이 실제로 쓴 측정·분석 기법 |
| 결론 | 논문이 결론을 냈는지, 냈다면 무엇인지 |

### 추측 금지가 실제로 뜻하는 것

**논문에 없는 것을 채우지 않는다.** 이 규칙이 필요한 이유는 연구 결과가 그럴듯하게 틀릴 수
있기 때문이다. 변인 구분이 비어 있는 논문에 "아마 온도가 독립변수일 것"이라고 채우면, 그
값이 이후 비교·해석·PPT까지 그대로 흘러가고 아무도 그게 추측이었다는 걸 모른다.

- 논문이 변인을 명시하지 않았으면 "명시 없음"이라고 적는다. 본문 맥락으로 유추한 것이면
  유추라고 표시한다.
- 결론이 모호하거나 "추가 연구가 필요하다"로 끝나면 그렇게 적는다. 결론을 정리해 주지 않는다.
- 초록만 보고 실험 세부를 적지 않는다. 초록에서 나온 것인지 본문에서 나온 것인지 구분한다.
- 수치를 옮길 때는 단위와 조건(온도·압력·조성)을 함께 옮긴다. 조건 없는 수치는 다른 조건에
  그대로 쓰이고, 쓴 사람은 그 사실을 모른다.

`assets/paper-note.md`의 「미확인·추정 표시」 칸을 비워 두지 않는다. 없으면 "없음"이라고
적는다 — 칸이 비어 있으면 확인한 것인지 빠뜨린 것인지 구분이 안 된다.

### 검토가 필요할 때

여러 편을 워커에 나눠 읽혔고 그 결과를 비교·해석에 쓸 거라면, `research-orchestration`
5절의 검토 항목으로 독립 검토를 붙인다. 특히 출처가 적힌 값이 정말 그 출처에 있는지
표본으로 역추적하는 항목이 여기 걸린다.

## 4. 실험 데이터와 대조할 때

사용자가 자기 실험 데이터를 가져와 논문과 비교하려 하면, 그 자리에서 대화로 해석을 돕는다.
별도 산출물 파일을 만들지 않는다.

대조할 때 먼저 확인할 것은 **조건이 같은가**다. 온도·압력·농도·촉매 같은 조건이 다르면
수치가 달라도 모순이 아니고, 같은데도 다르면 그게 논의할 지점이다. 조건을 확인하지 않고
값만 비교하면 없는 불일치를 만들어낸다.

3절의 추측 금지는 여기서도 같다. 사용자 데이터가 논문과 다를 때 그 원인을 지어내지 않고,
확인 가능한 것(조건 차이, 측정 방법 차이)과 알 수 없는 것을 구분해 말한다.
